# Parsing Lessons

Учебные проекты по парсингу сайтов на Python.

## Что умею

- Парсинг HTML через `requests` + `BeautifulSoup`
- Пагинация — обход нескольких страниц
- Парсинг карточек товаров (двухшаговый парсинг)
- Регулярные выражения для email и цен
- Сохранение в CSV и Excel (`openpyxl`)
- Обработка ошибок (`try/except`)
- Вежливый парсинг: User-Agent, паузы, robots.txt

## Проекты

- **books.toscrape.com** — 100 книг с ценами, рейтингом, категориями
- **quotes.toscrape.com** — 30 цитат с авторами и тегами
- **Сбор email** с сайтов организаций

## Как запустить

1. Установи зависимости: `pip install -r requirements.txt`
2. Запусти нужный скрипт: `python day14.py`
